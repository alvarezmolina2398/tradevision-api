API de analisis visual de establecimientos comerciales
Version 1.0 | 28 de agosto de 2026

1. Informacion general

La API analiza una o varias imagenes de un establecimiento y estima metricas comerciales, inventario, herramientas de trabajo, gastos, utilidad y puntuaciones visuales.

URL basehttps://innova.genesisempresarial.com/genesis-estimator
FormatoJSON para respuestas; multipart/form-data para el analisis.
AutenticacionHeader x-api-key, requerido unicamente en /analyze.
Documentacion interactivahttps://innova.genesisempresarial.com/genesis-estimator/docs
Seguridad: la clave API no se incluye en este documento. Guardala en una variable de entorno o en el gestor de secretos de tu plataforma. Como la clave fue compartida en una conversacion, se recomienda revocarla y generar una nueva.

2. Estado del servicio

GET/health

Endpoint publico para comprobar que el servicio esta disponible. No requiere API key.

3. Analisis de establecimiento

POST/analyze

Analiza imagenes del establecimiento. Requiere una API key valida y una peticion multipart/form-data.

Headers

HeaderValorObligatorio
x-api-keyTu clave privada de consumoSi
Content-TypeSe genera automaticamente como multipart/form-dataSi

Campos del formulario

CampoTipoObligatorioDescripcion
productTypeTextoSiTipo de producto o negocio esperado.
specialObservationsTextoNoContexto adicional, por ejemplo condiciones del terreno, acceso o ubicacion, para ajustar las estimaciones.
imagesArchivo, repetibleSiImagenes JPEG, PNG, WEBP o GIF.

Limites actuales: hasta 10 imagenes por solicitud y 10 MB por imagen.

Ejemplo con cURL

curl -X POST \
  "https://innova.genesisempresarial.com/genesis-estimator/analyze" \
  -H "x-api-key: TU_API_KEY" \
  -F "productType=abarrotes" \
  -F "specialObservations=Ubicado en una aldea; acceso de terraceria durante la lluvia" \
  -F "images=@./local.jpg" \
  -F "images=@./interior.png"

5. Errores

CodigoSignificadoCausa habitual
400 Bad RequestSolicitud invalidaFalta multipart, imagenes o productType.
401 UnauthorizedAPI key invalida o ausenteHeader x-api-key incorrecto o no enviado.
413 Payload Too LargePayload excedidoMas de 10 archivos o una imagen mayor a 10 MB.
415 Unsupported Media TypeTipo no permitidoLa imagen no es JPEG, PNG, WEBP o GIF.
422 Unprocessable EntityTipo no relacionadoLas imagenes no corresponden al productType indicado.
502 Bad GatewayError del analisisNo se pudo completar la comunicacion con el servicio de IA.

6. Configuracion del servidor

En produccion define las variables de entorno sin subir el archivo .env al repositorio:

PORT=3000
HOST=0.0.0.0
API_KEY=TU_API_KEY
OPENAI_API_KEY=TU_OPENAI_API_KEY
OPENAI_MODEL=gpt-4o

El proceso se inicia con:

pnpm start

Si se ejecuta con systemd, el servicio debe cargar el archivo de entorno y arrancar src/server.js.

7. Recomendaciones de consumo

  • Usa siempre HTTPS y no expongas la API key en aplicaciones frontend publicas.
  • Envia imagenes enfocadas, legibles y relevantes para mejorar la estimacion.
  • No registres el header x-api-key en logs.
  • Rota la API key si fue compartida, comprometida o incluida accidentalmente en un repositorio.
